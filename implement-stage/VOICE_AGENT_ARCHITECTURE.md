# MirrorMate 实时语音陪练：最小接入方案

## 结论

需要 **一个实时语音 Agent**，不需要多 Agent 编排。它的职责是把已确定的教学步骤说清楚、响应用户打断、调用受限的本地教学动作；视觉追踪和妆效渲染继续留在浏览器，不交给语音模型判定。

## 最小架构

```text
浏览器：麦克风 / 扬声器 / 当前步骤状态 / 本地人脸关键点
              │ WebRTC 音频 + 临时会话凭证
              ▼
受信任服务端：创建会话、保存 API Key、注入教学上下文、校验工具调用
              │
              ▼
实时语音模型：自然对话、可被打断的中文陪练
```

浏览器绝不保存长期 API Key。摄像头原始画面不传给语音服务；只在需要时传递极小的、可解释的状态，例如 `当前第 2 步 / 眼尾加深 / 用户点了求救 / 跟踪质量 ready`。

## 该 Agent 可以调用的受限工具

| 工具 | 结果 |
|---|---|
| `get_current_step` | 读出当前妆容、步骤、动作、提示和方向箭头 |
| `repeat_instruction` | 用更短或更慢的语速复述当前动作 |
| `go_previous_step` / `go_next_step` | 仅切换已经定义好的教学步骤 |
| `open_rescue` | 展开“画出界了”的预设补救卡 |
| `set_reading_speed` | 调整播报节奏 |
| `pause_coaching` / `resume_coaching` | 暂停或恢复引导 |

不开放“评价长相”“给颜值打分”“诊断皮肤”等工具；调整妆效浓度或切换风格需要界面明确确认，不能由对话自行修改。

## 对话系统提示词（第一版）

```text
你是 MirrorMate 的中文化妆陪练。只根据当前步骤和允许工具辅导用户。
每次只给一个可执行动作，先说刷具方向和范围，再说停止条件。
用户说“慢一点”“再说一遍”“画出界了”时立即调用对应工具。
绝不评价用户五官、颜值、肤色优劣，不做医疗或皮肤诊断，不推荐付费商品。
不知道时承认并建议查看镜面箭头或使用预设补救。
```

## 落地顺序

1. 在模型服务商项目中创建受限 API Key 和用量上限。
2. 部署一个服务端 `POST /api/realtime-session`：它根据当前教学状态创建短时音频会话，并将临时凭证返回浏览器。
3. 浏览器用 WebRTC 接入该临时会话，展示静音、挂断、字幕开关和“AI 正在听/说”的可见状态。
4. 将上表工具映射为前端现有的 `next`、上一步、朗读、补救状态；为每个工具调用记录不含音频的事件日志。
5. 用 10 分钟会话上限、随时打断、结束即断开、默认不保存音频完成隐私闭环。

## 参赛演示的降级策略

无网络或没有实时服务时，继续使用当前浏览器语音朗读和按钮控制；界面明确显示“离线引导模式”，不把它伪装成实时对话。
